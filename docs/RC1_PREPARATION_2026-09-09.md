## Corrections under native verification

Strict containment, reparse/symlink refusal and single-use generation behavior remain enforced. Existing canonical-path, replacement and concurrency tests exercise the corrected boundary.
- The Windows ACL helper invokes its script block explicitly through UTF-16LE `-EncodedCommand`, with each argument separately base64 encoded and decoded as data. The former trailing `-Command` arguments became script source instead of `$args`. [Microsoft's PowerShell CLI contract](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_powershell_exe?view=powershell-5.1) documents this distinction. The subsequent native run exposed a second PowerShell 5.1 parser defect: multiline boolean operators must end the preceding line; this is corrected without changing the predicates. Independent complete-pair review then found that ASCII-only apostrophe escaping leaves smart quotes interpreted as delimiters ([PowerShell quoting rules](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_quoting_rules?view=powershell-5.1)); argument data now enters only through fixed base64-decoding expressions. The failed r2 package remains unadmitted. The r3 native run then reaches module loading but fails to autoload `Microsoft.PowerShell.Security` from a PowerShell-7-launched Node environment; the helper now confines its child-process module search to the selected Windows PowerShell runtime’s own `$PSHOME/Modules`, with a native regression against a caller-owned conflicting security module. This follows the [documented inherited-module-path incompatibility](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_psmodulepath?view=powershell-7.4). Fresh native execution is still required. Unit checks preserve every volume/ancestor/leaf validation; a native Windows test exercises spaces, ASCII/smart apostrophes, Unicode and PowerShell-shaped text in a real disposable directory name.
- Export-companion path and command-inventory tests now express native filesystem separators and normalized report labels respectively; exported companion names and actual authorization policy are unchanged.
- Regional eligibility and rendering avoid allocating an empty child array per non-group object, and reserve recursive cycle bookkeeping for groups. Missing-object/cycle rejection and exact render eligibility remain covered.
