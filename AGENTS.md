# AIDraw project context

Before substantive work, read the live Secretary shared directory configured by this host's global startup guidance: `shared/README.md`, `shared/INTENT.md`, and `shared/projects/aidraw.md`. The AIDraw shared document is the maintained summary of product intentions, accepted major decisions, current work, and unresolved choices. If the live directory is unavailable, report the access problem to the designated manager or Secretary rather than treating a historical handoff as current context.

Read the relevant project specifications after that context:

- [README](README.md) for the product surface and boundaries.
- [Feature tracker](docs/FEATURE_TRACKER.md) for feature status, exit criteria, and the recommended critical path when product work is authorized.
- [Architecture](docs/ARCHITECTURE.md), [MCP contract](docs/MCP.md), and [file format](docs/FILE_FORMAT.md) for the affected implementation contract.
- [Contributor guidance](CONTRIBUTING.md), [testing workflow](docs/TESTING.md), and [release checklist](docs/RELEASE_CHECKLIST.md) for applicable validation and evidence limits.

Current user instructions govern the job. Dated tracker checkpoints, test reports, and `.codex/SECRETARY_HANDOFF.md` are evidence for their exact subjects; their old worktree state, next actions, and run permissions do not start new work. Preserve recovery stashes and unique incident/acceptance evidence. Distinguish source checks, exact-package behavior, installed/vendor-client acceptance, and release readiness.

The designated manager maintains `shared/projects/aidraw.md`; workers read it and report meaningful decisions or outcomes to that manager. Refresh relevant shared context after decisions or contacts change. Communication with other managers, including Secretary, is always authorized by the user and needs no repeated permission. Use the shared manager directory and supported task messaging, verifying the destination task and saved project first. Follow the shared access fallback if an authorized update cannot be written. Keep one current shared summary rather than copying it into local handoff files.
